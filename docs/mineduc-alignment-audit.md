# Ecuador MINEDUC alignment audit

**Audit date:** 2026-10-06
**Backlog update:** 2026-10-06 — P1 follow-ups are now [DEMY-147](https://emilioandresalcivarcarrera.atlassian.net/browse/DEMY-147), [DEMY-148](https://emilioandresalcivarcarrera.atlassian.net/browse/DEMY-148), and [DEMY-149](https://emilioandresalcivarcarrera.atlassian.net/browse/DEMY-149).
**Scope:** Zerocademy's currently implemented ordinary-school academic model. This
is an audit, not a redesign. DEMY-146 and DEMY-134 are treated as completed
unless a concrete contrary finding is identified.

## Executive conclusion

**Overall status: ALIGNED WITH GAPS.** The national hierarchy, the two
regimes, period-scoped course/assignment model, representative scope, planning
and execution separation, and auditable grade publication are compatible with
the official framework. The material gaps are in making the Ecuador evaluation
template scope-aware and in representing the official study-plan minimums before
TeachingLoad is exposed as an API.

The audit is limited to ordinary education. EPJA, intercultural bilingual,
specialized, virtual, intensive and complementary offers have distinct rules and
are **OUT_OF_SCOPE** for the current product unless an institution explicitly
offers them.

Repository evidence was taken from the complete Prisma schema, migrations
through `20261004181000_backfill_academic_sublevels`, canonical seeds, services,
controllers, frontend labels, docs, and relevant unit tests. Existing Jira work
was searched from repository links and a public Jira search; no authenticated

## Timetables gate

`PeriodScheduleStructure` remains compatible because it configures, rather than assumes, the local day and block arrangement. `TeachingLoad.weeklyPeriods` is compatible only as a scheduling input; it must not be represented as an unconstrained substitute for the official study plan.

- **DEMY-135 CAN PROCEED.** Its API can expose period-scoped weekdays, blocks and breaks without committing to a national duration or shift.
- **DEMY-136 BLOCKED BY `MINEDUC-STUDY-PLAN-CATALOG`.** Without an offer/course/version-aware source of official minimum loads, a load-configuration API would either silently allow below-minimum canonical loads or hard-code non-universal values. The unblocker is a small, versioned catalog/defaults design—not a full curriculum-destreza implementation.

## Changes made by this audit

Only terminology/documentation fixes were made:

1. The academic-period UI now calls generic records **términos del período**, avoiding an incorrect assumption that every institution uses trimesters.
2. User documentation now describes terms as trimester/quimestre examples instead of treating quimestre as universal.
3. Evaluation documentation now identifies the Ecuador template as a scoped reference, not a universal rule.

No schema, migration, seed catalog, grading behavior, timetable, or product workflow was changed.
